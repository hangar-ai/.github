# Security policy

**Please do not open a public issue for a security problem.**

Report it privately through GitHub Security Advisories: open the **Security** tab of the repository
concerned, click **Report a vulnerability**, and fill in the form. Only the maintainers can see it.

Please include the kit and its version, what an attacker can do and what they need first, and the
steps to reproduce.

Hangar and its kits are maintained by one person, so please allow some time for an answer.

## Scope

- **In scope:** the kits of this organization, the catalog, and the checks in this repository. A
  catalog entry that is not what its kit does is a security problem too.
- **Hangar itself:** report it on [its own repository](https://github.com/hangar-ai/hangar/security).
- **A community kit:** report it to its author, and tell us through the catalog's Security tab so that
  its entry can be reviewed.
- **Out of scope:** the agent CLIs a kit works with, and what you accepted when you enabled a kit:
  a kit's commands and hooks run with your user account, and are shown to you before they do.

Listing is not a guarantee. The catalog's review reads a kit at one tag; `verified` says who maintains
it, not that it cannot be wrong.
